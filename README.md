# 자분뽀 2주차 실습 프로젝트

회색 와이어프레임 상태의 웹툰 앱 홈 화면입니다. 이걸 내 스타일로 바꾸는 게 오늘 실습이에요.

## 파일 구성
- `index.html` : 실습할 페이지. 위쪽 `<style>` = CSS, 가운데 = HTML, 아래쪽 `<script>` = JS
- `tweaker.html` : 조절기. 글자·위치·이미지를 고치고 Claude에게 보낼 문장을 복사해 줍니다
- `images/` : 이미지 폴더. 바꿀 이미지는 여기에 넣으세요

## 실습 순서
1. `index.html`을 브라우저로 열어보기 (모바일로 보기: 우클릭 → 검사 → 휴대폰 아이콘)
2. `tweaker.html`을 열고 "HTML 파일 열기"로 `index.html` 불러오기
3. 요소 클릭 → 조절 → "복사"
4. Claude Code에 붙여넣기
5. 이미지를 바꿨다면 그 파일을 `images/` 폴더에 넣기

## 주의
